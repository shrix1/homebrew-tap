# WrapScribe Homebrew tap

Install [WrapScribe](https://wrapscribe.com) — on-device dictation for macOS:

```sh
brew tap shrix1/tap
brew install --cask wrapscribe
```

Requires macOS 26 (Tahoe) on Apple Silicon. The app updates itself in-app; the cask is refreshed on each release by the WrapScribe release pipeline.
